3 Scan QR and Order Flow 
1) User scan the qr code if user scan the shop qr then it will show shop details and if user scan table qr user will see the shop food menu 
2) User will see the food menus, deals of the shop now he will choose the items and create an order = order initiated
3) due to real time data transfer it will reflact to the owners dashboard now owner will confirm it for = order preparing
4) user will enjoy their food and now he paid bill using offline or other upi apps we are not traking any payment data yet 
5) before/after paying the bill user can request owner to complete the order for this shop owner side will show Complete Order option by clicking it an passkey of 4 digit will available to user side this passkey will be entererd by shop side and Complete the order
6) after completeting this process the coin amount of the order will be deducted from shop account and credited to users wallet 

4 Redeem the coins 
1) Redeem by shop owner - after reaching an specified limit of coins shop owner can be able to redeem the coins to real money shop owner will provide upi details using update the profile part these detail will be verify by superadmin and after verify the the real money will be credited to owners bank account by that upi the amount of money can be set by superadmin like 1coins equal how much rupee based on it money will be transfer 
2) On redeem time - all the coins can not be able to redeem always the some % of coins will be required to keep in wallet
3) redeem by user - user is also need to provide upi detail to add the balance to their account
